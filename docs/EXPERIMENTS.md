## 상세

### #2·#3 피처 사다리 (덩어리 3)
- **측정 모델 (고정)**: L2 로지스틱 회귀(C=0.1), LightGBM(트리 300개, 잎 7개, 학습률 0.02). 설정은 `src/models.py`에 있다.
- **채택 규칙 (결과를 보기 전에 정함)**: 두 모델 AUC의 fold별 평균이 직전 채택 상태보다 평균으로 오르고, 5개 fold 중 4개 이상에서 오르면 채택한다.
- 점수는 cv5에서 두 측정 모델 AUC의 평균이다. 괄호 안은 직전 채택 상태 대비 개선된 fold 수다.

| 단계 | Target_1 (KOSPI) | 결정 | Target_2 (건강식품) | 결정 |
|---|---|---|---|---|
| 기준: 원본 변수 | 0.504 | - | 0.927 | - |
| 핵심 묶음 | us_change 0.572 | 시작점 | weekday 0.936 | 시작점 |
| 2단계 | + us_composite 0.562 (2/5) | 기각 | + traffic 0.954 (4/5) | 채택 |
| 3단계 | + us_trend_vol 0.607 (5/5) | **채택** | + weekday_dev 0.959 (4/5) | **채택** |
| 4단계 | + macro_change 0.570 (2/5) | 기각 | + food_health 0.958 (2/5) | 기각 |
| 원래값 추가 | + raw 0.572 (1/5) | 기각 | + raw 0.933 (2/5) | 기각 |

- **해석**
  - KOSPI는 미국 지수의 단기 변화와 중기 추세·변동성만으로 가장 좋다. 환율·유가 등을 더하면 오히려 잡음이 늘어 나빠진다.
  - 건강식품은 요일에 전체 트래픽 흐름과 같은 요일 대비 이상도를 더하면 개선된다. 식품 개별 품목은 효과가 없다.
  - 두 타깃 모두 **원래값을 더하면 나빠진다.** EDA의 드리프트 발견과 같은 방향이다.
- **주의**
  - 묶음 선택에 cv5를 썼으므로 #4의 cv5 점수는 다소 낙관적이다.
  - holdout200은 cv5의 마지막 두 fold와 기간이 겹쳐 독립 검증이 아니다.
  - 평가 기간(코로나 시기)의 실제 점수는 이보다 낮을 수 있다.

### 독립 코드 검토 반영 (피처 누수 점검)
검토 결과 미래 정보 누수와 train/test 불일치는 없었다. 아래 4가지를 보완한 뒤 #2~#4를 다시 실행했다. **채택·기각 결정은 모두 그대로**이고 점수 변화는 ±0.014 이내다.

1. **누수 테스트의 사각지대**
   - 기존 검사 지점이 모두 평일이었다. 그래서 주말 값을 미래에서 끌어오는 버그(bfill, interpolate, 미래를 보는 거래일 판정)가 통과했다.
   - 검사 지점을 train/test 경계 앞뒤 15일(모든 요일 포함)로 넓혔다. 위 3가지 버그를 일부러 심어 모두 잡히는 것을 확인했다.
2. **거래일 판정**
   - "값이 그대로면 휴장일"로 판정하면, USDKRW처럼 실제 거래일에 값이 같았던 날(43일)을 휴장으로 오인한다.
   - 이제 같은 시장 그룹(미국 지수, 원화 환율, 유가, 원자재) 중 하나라도 움직이면 거래일로 본다.
3. **결측 방어**: 거래일 변화 계산의 ffill이 결측을 오래된 값으로 덮지 않도록, 설명변수에 결측이 있으면 즉시 오류를 낸다 (현재 결측 0개).
4. **초기 구간**: 같은 요일 평균을 4주치가 모이기 전에는 계산하지 않는다 (train 초반 21행에만 해당).
